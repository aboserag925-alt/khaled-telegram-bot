# بوت جروب الدكتور خالد الحارس

بوت تليجرام لجروب «إستراحة أهل الأثر». يحفظ التسجيلات بمعرّف الملف (file_id) دون إعادة رفعها، ويصنفها في أقسام، ويبحث فيها، ويعرض جدول البث.

النسخة الأولى. لم تُجرَّب على تليجرام بتوكن حقيقي بعد.

## الأوامر

- /بحث كلمة: بحث في عناوين التسجيلات
- /قسم اسم القسم: عرض قسم (بدون اسم: عرض الأقسام)
- /جديد: آخر المضاف
- /جدول: جدول البث بتوقيت مصر ومكة
- /روابط: يوتيوب وتيك توك وتليجرام
- /تصنيف رقم القسم: للمشرف، تغيير قسم تسجيل

لكل أمر بديل لاتيني: search, section, new, schedule, links, setcat.

## خطوات التشغيل (عليك أنت)

1. من BotFather في تليجرام أنشئ بوتًا جديدًا (أمر newbot) واختر اسمه. ستحصل على رمز الوصول. لا ترسله لأحد ولا تضعه في الكود.
2. أضف البوت إلى الجروب. ومن BotFather عطّل وضع الخصوصية للبوت (setprivacy ثم Disable) كي يرى رسائل الجروب.
3. في Railway: New Project ثم Deploy from GitHub repo واختر هذا المستودع.
4. في Variables أضف BOT_TOKEN بالرمز. واختياريًا: ADMIN_IDS (معرّفات المشرفين الرقمية مفصولة بفاصلة)، ARCHIVE_CHAT_IDS (معرّف المحادثة التي تُؤرشف تسجيلاتها تلقائيًا)، YOUTUBE_URL وTIKTOK_URL وTELEGRAM_CHANNEL_URL، وBOT_NAME.
5. قاعدة البيانات ملف SQLite. أضف Volume على المسار /data وضع DB_PATH=/data/bot.db كي لا تُمسح البيانات عند كل نشر.
6. نوع الخدمة Worker، والتشغيل من ملف Procfile.

## إضافة التسجيلات

- التسجيل الجديد يرسله مشرف للبوت (أو يُنشر في محادثة داخل ARCHIVE_CHAT_IDS) فيُصنَّف تلقائيًا حسب عنوانه ويُحفظ file_id فقط.
- العنوان: عنوان الملف الصوتي، أو أول سطر من الوصف.
- ترتيب صحيح مسلم بالرقم: إن وُجدت في العنوان كلمة مجلس أو درس أو حلقة متبوعة برقم.
- الأرشيف القديم (211 ملفًا): يلزم تصدير أو قائمة file_id. أداة الاستيراد الجماعي غير مكتوبة بعد.

## الجدول

عدّل الملف schedule.json مباشرة.

## الاختبارات

الأمر: python -m unittest discover -s tests -v

تغطي التصنيف والبحث والترتيب والجدول. لا تغطي الاتصال بتليجرام.

توقيع «فارس السنة» يظهر في ذيل رسائل البوت. مرحلة لاحقة: تنبيه قبل البث.
